## 🔧 Troubleshooting Common Issues

**"The application won't start"**
- Make sure your graphics drivers are up to date (check your GPU manufacturer's website).
- Try running the application as administrator (right-click > Run as administrator).

**"Training is too slow"**
- Close other programs that use heavy graphics (games, video editors).
- Reduce the model size in settings if you're low on RAM.

**"I can't find my downloaded file"**
- Check your Downloads folder. If you see a `.zip` file instead of `.exe`, extract it first by right-clicking and selecting "Extract All."

**"The app asks for Vulkan support"**
- Update your GPU drivers to the latest version. Most modern graphics cards support Vulkan.
